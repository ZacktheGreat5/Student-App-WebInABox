# UVU Student Application

This is a simple React application created for a university assignment.

## Information Displayed

The application displays:

- My full name
- My UVU student ID

## Technologies Used

- React
- Vite
- Docker
- Nginx

## Running the Application

Build the Docker image:

```bash
docker build -t student-app .
